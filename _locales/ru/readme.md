# TK Tree Style Tab Outliner (TKTSTO)

Окна, вкладки, закладки, заметки, задачи и многое другое... всё в одном месте — в структурированном интерактивном документе для организации вашей работы в интернете.

Расширение заменяет большинство встроенных функций браузера: закладки, менеджер сессий, вертикальные вкладки, списки «прочитать позже», заметки и списки задач.

## Преимущества и возможности

- **Бесплатность и открытый исходный код** (AGPLv3).
- **Непрерывное сохранение сессий и резервное копирование**.
- **Синхронизация между разными браузерами** (Chrome, Firefox, Brave, Edge, Vivaldi и др.).
- **Экспорт данных** в форматы JSON, Markdown и обычный текст.
- **Интерактивные списки задач (ToDo / Checkboxes)** и заметки.
- **Гибкий поиск по дереву** с поддержкой регулярных выражений.
- **Горячие клавиши** для управления деревом с клавиатуры.
- **Поддержка Manifest V3**.


## Первые шаги

1. **Откройте боковую панель**:
   - `Alt+T` в браузерах на базе Chrome.
   - `F1` в браузерах на базе Firefox.

2. **Запустите интерактивное обучение**:
   - Кликните по боковой панели и нажмите клавишу `?` на клавиатуре.

3. **Выгружайте ненужные вкладки**:
   - Нажмите `Alt+U` (или `U` на панели), чтобы выгрузить вкладку из памяти. Она сохранится в дереве и откроется позже по клику.

4. **Организуйте дерево**:
   - Нажмите `o` для создания метки, `Shift+Стрелки` для перемещения или `M` (отметить) + `P` (вставить) для переноса веток.

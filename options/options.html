Client ID

Each browser you use needs its own unique identifier. Use something short with no spaces or punctuation, because it will become part of the ID for each tree node and transaction created by that browser. For example:
  • If you have computers "alice", "bob", and "carol", all using the same type of browser, they could be simply "a", "b", and "c".
  • Or perhaps you use six browsers and call them "wdc", "wdf", "wn", "hd", "hn", and "pf". This would be short for "work desktop chrome", "work desktop firefox", "work notebook", "home desktop", "home notebook", and "phone firefox".

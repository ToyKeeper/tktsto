First Steps with TKTSTO

Welcome to TK's Tree Style Tab Outliner (TKTSTO)! This page covers the basic concepts to help you get started quickly.

1. Opening the Side Panel

TKTSTO operates primarily from your browser's side panel:

  • Chrome / Chromium / Edge / Brave: Press Alt+T or click the extension icon in your toolbar to toggle the side panel.
  • Firefox / Floorp / Zen: Press F1 to open the sidebar.

2. Interactive Tutorial

To start the built-in interactive tutorial at any time:

  • Focus the TKTSTO side panel by clicking inside it, then press the ? key on your keyboard.

This will generate interactive tutorial nodes at the top of your session tree to guide you through basic tree manipulation.

3. Basic Concepts

  • Unloading Tabs: Press Alt+U (or U when panel is focused) to unload an active tab. It stays saved in your tree so you can re-open it later without using RAM.
  • Adding Nodes: Press o to add a new label node below the cursor. Use labels, notes, and checkboxes to organize your workflow.
  • Moving Nodes: Use Shift+Arrow keys or click M to mark nodes and P to paste them into another location or window.
  • Window vs Session Mode: Toggle between viewing only the current window or your entire multi-window session using the button at the top-left of the panel.

Explore the other help pages for more details on bookmarks, checkboxes, user styles, and migration!

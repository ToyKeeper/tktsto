Pink text is a "wasLoaded" tab.

It means the tab was loaded when your session was saved, or when a window was last closed. When you open a saved window, all the pink wasLoaded tabs will be opened automatically and become loaded tabs. The regular grey unloaded tabs (like bookmarks) will not be opened automatically.

So if you didn't change anything, this window should have only one tab open. The "Pink text ..." tab should be open, while the "Grey text ..." tab is not.

This means you can save and restore windows (close and re-open) with just a click or two. I think that's pretty neat.

By the way, this would be a good time to try clicking the button in the upper left corner of the sidepanel. It should say "Session" or "Window".

That's the "viewScope" button, or the "Session / Window" button. It changes how much of the tree is visible in the current window's sidepanel. I keep most of my windows in "Window" mode so I can focus on one window at a time. But sometimes it's useful to switch to a full session view, for larger session management tasks, like moving windows around or re-opening saved windows.

Anyway, when you're done reading this, try closing this window. There are a few ways to do it:

  • Click the "X" button on the top right corner of the browser window. Depending on your computing environment, this button may or may not exist. Just close it like you would close any other window. Another popular method is Alt+F4.
  • Some browsers have a hotkey to close a window, like Shift+Ctrl+W.
  • Hover the mouse over the window row in the tree view, and click the U button (Unload) in the hover menu.
  • With the sidepanel focused, and the cursor on the tree row, press the U key on the keyboard.
  • With the cursor on the tree row, press the Alt+U key on the keyboard. This works even if the sidepanel isn't focused, using the browser's extension shortcuts feature.

When you close a browser window, it is always saved in the tree unless it's "boring" (has no metadata) and completely empty. So don't be shy about closing windows when you're not using them. You can get them back later.

Oh, and if you want to change a tab between "unloaded" and "wasLoaded" states, just keep pressing the U button. This lets you manually set which tabs will be auto-loaded when you open the window.

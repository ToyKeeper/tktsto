If you're migrating from Tabs Outliner, there are a few things which would be helpful to know.

Data transfer

Back up your data in Tabs Outliner first. Do an export or backup if you can... and if not, at least do an "expand all nodes" and then Ctrl-S to save the page.

The backup files are in .json format, and can be imported into TKTSTO directly. However, you may need to rename the backup file extension from .tree to .json before importing it.

Saved session view pages can be converted to a usable format using an extra script called bin/tabs-outliner-html-to-tktsto-json.py. You'll need to clone the TKTSTO git repository to get this script.

Once you have a backup file in .json format, import it into TKTSTO. Open the Options page, then look for the Import section. A Tabs Outliner .tree backup file can go into the "Tabs Outliner files" box, or a saved html page converted via the script above goes into the "TKTSTO files" box.

Doing a Tabs Outliner backup when you have the free version

Daniel contributed this handy tip:

Little tip for anyone looking to switch from Tabs Outliner to TKTSTO:

You can export a backup from Tabs Outliner for import into TKTSTO without having to buy a Paid Mode Premium Key.

  1. open the options page in Tabs Outliner
  2. go to the "Backup" tab
  3. right click in the whitespace somewhere on the page, for example in the space between the first two text paragraphs. Then select "Inspect".
  4. the developer tools will open. The "Elements" tab should be open, if not, switch to it.
  5. In there, an entry <div id="licenseKeyAbsentBackupTabBlock" style=""> is likely selected. Search for another entry, <div id="licenseKeyPresentBackupTabBlock" style="display: none;">, right next to it, and select that one. (You can also ctrl+f and search for "licenseKeyPresentBackupTabBlock" to find it).
  6. double click on the display: none to edit, and delete that text, such that the line becomes <div id="licenseKeyPresentBackupTabBlock">
  7. The backup options will now have appeared at the bottom of Tab Outliner's Backup page.
  8. Click on "Export Tree to File" to create your Tabs Outliner backup.
  9. Rename the file ending .tree to .json.
  10. Now you can import the backup into TKTSTO.

These instructions are for Chrome, which should probably be most relevant for Tabs Outliner. Other browsers are similar though.

Session View Window

Tabs Outliner pretty much forced users to keep a separate window open to see the session tree, and it contained the entire session. If you want this, TKTSTO can be configured to work that way:

  1. Open a window.
  2. Open the TKTSTO side panel.
  3. Click the "Tab" button in the side panel to open a tree view in a new tab.
  4. Close the side panel.
  5. Click the "Window" button to put it in Session mode if it isn't already.
  6. Position the window however you want, and keep it open.
  7. Would also be a good idea to give the window node a name, and give the tree view tab a name, to make sure they won't accidentally get deleted. Name anything you want to keep, or otherwise attach something to it, like a note or a checkbox, to prevent accidental deletion when the window or tab is closed.

However, it is not recommended to use the old Tabs Outliner workflow... because TKTSTO has something better. Instead of having a separate window for the session view, reclaim that space and make your browsing window(s) bigger. Then open the side panel whenever you want to do outliner type tasks. The sidepanel can be opened or closed with Alt+t in Chrome-based browsers, or F1 in Firefox-based browsers, or whatever key you assign it to.

Tabs Outliner had a feature to scroll the tree view any time a window is focused, to scroll to that window's part of the tree. This is unnecessary in TKTSTO, because you can instead just use the side panel in "Window" view mode. It only shows the contents of that single window.

Additionally, TKTSTO scrolls the sidepanel to make the current tab visible whenever you change tabs. So even with a very large session, it will generally keep the current section visible automatically.

To move things between windows, use "mark and paste". Mark the nodes in one window, then switch windows, and paste them into the second window's tree view. You could drag nodes using the mouse, but marking is faster and easier, especially with a keyboard. There is no need to drag items individually, or group them all under a single branch first. Just mark as many as you like. And there is no need to scroll long distances between windows. Simply mark, change windows, place the cursor where you want them, then paste. More info is in the tutorial, in the Moving Nodes page.

Mouse / Keyboard support

Tabs Outliner had keyboard support, but it was locked behind a paywall. Organizing the tree with a mouse is a pain, so this was a pretty effective way to get users to pay for the real version.

TKTSTO doesn't lock away the keyboard support... and it is strongly recommended that you use a keyboard for tree management unless you don't have a keyboard on your device. It's much, much faster.

It would also be a good idea to configure your extension shortcuts, to let you do tree management when the sidepanel isn't focused. The recommended config is to duplicate your regular key mappings, but add Alt.

Hover menu

TKTSTO has a hover menu which is very similar to Tabs Outliner. However, items are rearranged to help prevent unwanted actions, like deleting a node when you meant to unload or edit it.

The hover menu is also kind of annoying. So it hides itself while using a keyboard, and after you get accustomed to the keyboard controls, it may be helpful to turn off the hover menu entirely.

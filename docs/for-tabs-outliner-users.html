If you're migrating from Tabs Outliner, there are a few things which would be helpful to know.

Data transfer

Back up your data in Tabs Outliner first. Do an export or backup if you can... and if not, at least do an "expand all nodes" and then Ctrl+S to save the page.

The backup files are in .json format, and can be imported into TKTSTO directly. However, you may need to rename the backup file extension from .tree to .json before importing it.

Saved session view pages can be converted to a usable format using an extra script called bin/tabs-outliner-html-to-tktsto-json.py in the TKTSTO repository.

Once you have a backup file in .json format, import it into TKTSTO via the Options page -> Import section.

Doing a Tabs Outliner backup when you have the free version

Daniel contributed this handy tip for exporting backups without paying for Premium Mode in Tabs Outliner:

  1. open the options page in Tabs Outliner
  2. go to the "Backup" tab
  3. right click in the whitespace somewhere on the page and select "Inspect".
  4. the developer tools will open on the "Elements" tab.
  5. find the element with id "licenseKeyPresentBackupTabBlock" (which has style="display: none;").
  6. double click display: none to edit and delete that text.
  7. The backup options will now appear on the page.
  8. Click "Export Tree to File" to create your backup.
  9. Rename the file ending .tree to .json.
  10. Now you can import the backup into TKTSTO.

Session View Window

Tabs Outliner forced users to keep a separate window open for the session tree. TKTSTO can work that way, but provides a better built-in sidepanel workflow.

Instead of keeping a separate window open for the session view, reclaim that space and use TKTSTO's sidepanel (Alt+T in Chrome, F1 in Firefox). In "Window" mode, it automatically displays only the active window's tabs.

To move items between windows, use "mark and paste" (M to mark, P to paste), which is much faster and easier than drag-and-drop between separate windows.

Mouse / Keyboard support

Unlike Tabs Outliner, TKTSTO keyboard shortcuts are 100% free and not locked behind a paywall. Using the keyboard for tree management is strongly recommended.

Hover menu

TKTSTO has a hover menu similar to Tabs Outliner, but rearranged to prevent accidental deletion. It automatically hides when using the keyboard.

Checkboxes let you make "ToDo" lists.

Expand the "Checkboxes" branch if you haven't already. Looks like somebody is doing some grocery shopping... but they didn't organize their list yet! Let's help them out, and try 3 different ways of moving nodes around.

  1. First, try using the mouse to drag the "Milk" item into the "Cold aisle" branch.
  2. Second, press the Up arrow a few times to move the cursor to "Crackers". Then press Shift+Down to move it down a row or two. It should now be in the "Dry / Canned" branch.
  3. Third, mark the nodes for "Ice cream" and "Popsicles", since they both need to be frozen. You can mark them by pressing the M button in the hover menu, or by pressing the M key while the cursor is on those rows. Then move the cursor down to "Frozen" and press P to paste. Then press Shift+M to unmark them.

That just leaves "Soup" remaining to be sorted. Use whatever method you like.

Then you remember you also need butter. Put the cursor somewhere in the "Cold aisle" branch and press the o key to open a new node on a new row. It'll ask you for a label, so type in "Butter" and press Enter. (the o and Shift+O keys are mapped by default to "addNodeAsNextVisibleRow" and "addNodeAsPrevVisibleRow", which match the keys used in Vim, a popular editor)

But "Butter" doesn't have a checkbox like all the other items.

To add a checkbox, you can either press the T key or click the T button in the hover menu. This brings up the "taskEdit" dialog.

Next, either click on the style of checkbox you want, or press a key on the keyboard with a printable letter on it. It can be any letter or symbol, so you can assign your own meanings to different symbols. For a simple " todo" checkbox, just press Space.

Quick Task Edits

For quick edits, put the cursor on a row and then press a short key sequence, like t and then Space to add a " todo" checkbox... or tx to mark a task as "Xdone". Or t then Backspace to remove the checkbox. (t then Delete also works)

Maybe you already have cheese, for example. Everyone should have cheese, which is why it is marked as "!important". But you're a hoopy frood who already has some. So move the cursor to "Cheese" and type tx to mark it as "Xdone". Note how the percent boxes change in response to this.

Other Task Types

There are a few other types of tasks pre-defined...

  • The "%percent" checkboxes calculate their own number if they have any children with checkboxes. Otherwise, you can set the value manually by typing something like t42 for 42% or t07 for 7%.

  • To set a priority of 1 to 9 instead, try t3 then press Enter to set a task to priority 3.

  • A "/ratio" checkbox works a lot like a "percent" checkbox, except it displays a count of completed vs total child tasks, like 3/7 if you had 3 tasks done out of 7 total. Sometimes it's nice to have a counter instead of a percent.

User Styles

In the "user styles" config option, you can enter any CSS you want, to change the appearance of the Tree Views and other TKTSTO pages.

For example, this is what someone might write there to make rows light up purple when the mouse passes over them, and hide the hover menu, and increase the spacing between rows a little bit: 

/* highlight the row under the mouse in purple */
.row:hover {
  background: linear-gradient(#62116c, #2f183b) !important;
  outline: var(--1px) solid #f0f8 !important;
  border-radius: 0.5em;
}
.row:hover * {
  /* very light purple text */
  color: #fcf !important;
}

/* don't show the hover menu at all, ever */
#hover-menu {
  display: none;
}

/* put some space (and a drop target) between top-level items in a window */
.window.node > .nodes > .node {
  padding-bottom: 0.75em;
}

:root {
  /* space out the rows a little bit */
  --row-padding: 0.1em;
}

To see what specific stylings might be useful to override, take a look at the default theme base, the night theme, and the day theme. Particularly the parts at the bottom, inside of :root { ... } because those variables are relatively easy to modify.

... and if you make a cool theme, send it in so it can be included for everyone else to use! <3

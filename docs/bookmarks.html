Bookmarks

Bookmarks are usually not necessary when you can just Alt+U a tab you want to come back to later.

However, sometimes a bookmark can still be useful. Bookmarks provide a consistent starting point which does not change if you navigate to another page. You open it, navigate however you like, and the bookmark stays the same so you can start from the same page next time.

This is helpful when a site requires you to log in every day, so you can bookmark the login page and then immediately navigate away to some other page. Or if you frequently check a news site, and want to always start on the front page, but also want to go to other pages without opening new tabs. Or if you otherwise want to lock a saved tab so the URL and title won't change while you're browsing.

Bookmarks in TKTSTO are essentially the same as an unloaded tab, except for a few small differences:

  • It has a bookmark icon.
  • When loaded, it opens as a new node, leaving the bookmark itself unchanged. The new node will be the first child of the bookmark node.

There are two ways to make a bookmark:

  • Press Alt+B (or Alt+K in Firefox) to bookmark the current tab. This will create a new bookmark node and make it the parent of the current tab's node.
  • Press E or click E to Edit Node on an unloaded tab in the Tree View, then set its "Bookmark?" checkbox and save the changes. This converts an unloaded tab into a bookmark.

Tip: If you want a tab to open next to the current tab instead of opening as a child of a bookmark node, just middle click the node. This works for any tab node, not just bookmarks. Because tab nodes are links. You can middle click any tab node, whether loaded or unloaded, to open that node's URL in a new tab, and it will be placed the same as if you middle-clicked a link in the current page. So every tab node can be used like a native browser bookmark, even if it doesn't have a bookmark icon in the Tree View.

Another tip: When you open a bookmark in the Tree View, the bookmark's mtime gets updated. It also gets updated when you close-and-delete the clone it spawned. This provides an easy way to automatically track when you last used a bookmark. Just enable the Details panel in the Tree View and check the mtime. Pretty handy if you have a news site bookmarked, and you want to know how far back to read before you'll get to articles you've already seen. Just be sure to check the mtime before you open the bookmark.

Native Browser bookmarks

The browser's built-in bookmarks are not supported yet. TKTSTO provides a separate, alternate bookmark system, so you can more easily take your bookmarks with you if/when you change browsers, and not have to rely on a "Sign in to Chrome" type feature to sync between browsers.

However, a future version of TKTSTO may add some type of support for native bookmarks... at least enough to import them into the session tree.

A future version may also potentially add support for the "omnibar", to suggest TKTSTO bookmarks related to the current window.

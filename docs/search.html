Search

To search the tree, a few commands are available:

  • / : Start a search, or re-focus the search bar during a search.
  • Shift+* : Start a search for anything matching the current node's label, title, url, or note. Returns focus to the tree view immediately since no further search details can be entered. Is useful for finding duplicates and similar items.
  • Enter while the search bar is focused: Give focus back to the TreeView, and keep the search active. Can also just Click in the TreeView to focus it.
  • N / Shift+N : Go to the next (or previous) match.
  • m / Shift+M / p : Mark the current node, unmark all nodes, or paste all marked nodes.
  • Escape : End or cancel the search.
  • Escape (again): Close any branches which were temporarily expanded to show hidden nodes.

One common workflow is to find everything matching a given query, then pull them all together into one place. To do this, type /foo to do a search for "foo", then press Enter to go back to the TreeView. Press n and m repeatedly to go to the next match and mark it. Then move the cursor to the place where you want all those nodes to be, and press p to paste everything. Finally, Shift+M to unmark everything, and Escape once or twice to cancel the search.

Search Terms

Searches look through all of a node's attached data. In particular, it checks the label, title, url, and note. If you don't see why a particular node was included as a match, open the details box to see more of the data it searched through.

Searches are made of one or more search terms, separated by spaces. Results only include nodes which match all search terms. Searches are not case sensitive. Each individual term is a regular expression, so it can be pretty complex if you like... but in most cases, it is easiest to just type a word or two.

The full scope of what regular expressions can do is way more than we can cover here, but here are a few simple tricks:

  • . matches any single character.
  • \. matches a literal . character, and also works to escape other special symbols.
  • x* matches any number of x characters, like ab*c would match abc, abbbbbbc, and ac.
  • x+ matches one or more x characters.
  • x? matches zero or one of x, making it optional.
  • x{n,m} matches at least n instances of "x", and can match up to m instances. Can also be used as x{n} for exactly n instances, or x{n,} for n or more instances.
  • ^foo matches "foo" but only at the beginning of a string.
  • foo$ matches "foo" but only at the end of a string.
  • [abc] matches any of the characters inside the brackets. It can also include ranges, like [a-z] would match any letter from a to z.
  • [^abc] matches anything except the characters inside the brackets.
  • (abc) groups everything inside it together, making it count as a single object. This can then have other modifiers, like (word)? to make the word optional, or (word)+ to match one or more of word in a row.
  • x|y matches "x" OR "y". This is typically used with groups, like (Alice|Bob|Carol|Dave)\s(Anon|Doe|Smith|Hacker) would match "Alice Smith", "Bob Doe", "Carol Hacker", "Dave Anon", and every other combination of the first group and second group.
  • \x matches a predefined set of characters, depending on what x is. \d is a digit, \D is anything except a digit, \w is the same as [A-Za-z0-9_], \s matches whitespace, \S matches non-whitespace, and there are a bunch more.

Examples:

  • face.*mess would match anything containing "face" and then "mess", with anything (or nothing) between. Like "Facebook Messenger". Or you could do am.*ing to match "amazing", "amending", "amusing", "clamping", "dreaming", "jamming", "rambling", and many other words.
  • (www\.)?(foo|bar|baz)\.(com|net|org) would match "www.foo.com", "foo.org", "www.bar.net", "baz.com", and every other combination of the second group and third group... both with and without a "www." at the beginning.
  • (\d{3}-)?\d{3}-\d{4} would match a certain type of phone numbers, like "123-4567" and "123-456-7890".

But most of the time, you probably won't need more than just a simple word or two, to find what you're looking for.

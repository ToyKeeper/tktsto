Search

To search the tree, a few commands are available:

  • / : Start a search, or re-focus the search bar during a search.
  • Shift+* : Start a search for anything matching the current node's label, title, url, or note. Returns focus to the tree view immediately.
  • Enter while the search bar is focused: Give focus back to the TreeView, and keep the search active. Can also just click in the TreeView to focus it.
  • N / Shift+N : Go to the next (or previous) match.
  • M / Shift+M / P : Mark the current node, unmark all nodes, or paste all marked nodes.
  • Escape : End or cancel the search.
  • Escape (again): Close any branches which were temporarily expanded to show hidden nodes.

One common workflow is to find everything matching a given query, then pull them all together into one place. To do this, type /foo to do a search for "foo", then press Enter to go back to the TreeView. Press n and m repeatedly to go to the next match and mark it. Then move the cursor to the place where you want all those nodes to be, and press p to paste everything. Finally, Shift+M to unmark everything, and Escape once or twice to cancel the search.

Search Terms

Searches look through all of a node's attached data. In particular, it checks the label, title, url, and note. If you don't see why a particular node was included as a match, open the details box to see more of the data it searched through.

Searches are made of one or more search terms, separated by spaces. Results only include nodes which match all search terms. Searches are not case sensitive. Each individual term is a regular expression.

The full scope of what regular expressions can do is way more than we can cover here, but here are a few simple tricks:

  • . matches any single character.
  • \. matches a literal . character, and also works to escape other special symbols.
  • x* matches any number of x characters, like ab*c matches abc, abbbbbbc, and ac.
  • x+ matches one or more x characters.
  • x? matches zero or one of x, making it optional.
  • x{n,m} matches at least n instances of "x", and up to m.
  • ^foo matches "foo" at the beginning of a string.
  • foo$ matches "foo" at the end of a string.
  • [abc] matches any of the characters inside brackets (e.g. [a-z]).
  • [^abc] matches anything except the characters inside brackets.
  • (abc) groups characters together.
  • x|y matches "x" OR "y".
  • \x matches a predefined character class (\d for digits, \w for word chars, \s for whitespace).

Examples

  • face.*mess matches anything containing "face" and then "mess", such as "Facebook Messenger".
  • (www\.)?(foo|bar|baz)\.(com|net|org) matches domains like "www.foo.com", "foo.org", "www.bar.net".
  • (\d{3}-)?\d{3}-\d{4} matches phone numbers like "123-4567" and "123-456-7890".

But most of the time, you probably won't need more than just a simple word or two, to find what you're looking for.

Pinned Tabs

Pinned tabs are supported, and get pinned (or unpinned) by moving them into (or out of) a special branch called "Pinned" at the top of a window.

To pin or unpin a tab:

  • Use the browser's native functions: Right click a tab in the browser's tab bar. In the pop-up menu, click the "Pin" or "Unpin" option. The tab should become pinned (or unpinned), along with all its child tabs.

  • Move nodes in the Tree View: Use TKTSTO's sidepanel to move nodes or branches into or out of the Pinned branch. The browser's internal pinned state will update accordingly.

The TKTSTO Tree View will generally be more reliable than the browser's native functions, so I recommend doing it that way in most cases.

Browser's native Pin / Unpin functions

Let's say you want to pin a tab called "Pin Me!". Right click on that tab in the browser's native tab bar, then click "Pin".

Note how a new node was created, called Pinned. This node is special. It cannot be moved while it has loaded tabs, so it has an anchor icon next to it. It is locked in place at the top of the window.

All the children of "Pin Me!" got pinned too. The nested branch structure is preserved.

If you change your mind and want to unpin it, right click on the "Pin Me!" tab again and click "Unpin":

The entire branch gets unpinned. And since the "Pinned" branch no longer has loaded tabs inside, its icon changes to a thumbtack icon.

Pin/Unpin using TKTSTO

If you have no "Pinned" branch yet, make one. Put the cursor on the window node, expand it, then press o to add a new node and set its label to "Pinned".

Then move nodes or branches into or out of the Pinned branch. The browser's internal pinned state and tab bar will update accordingly.

If you want to unpin everything, simply delete the "Pinned" node while it is expanded, or change its name.

Caveats / Known Issues

  • Vivaldi has special behavior when closing windows with pinned tabs. Using TKTSTO's Unload button to close windows in Vivaldi avoids losing pinned tab metadata.

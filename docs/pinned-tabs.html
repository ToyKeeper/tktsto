Pinned Tabs

Pinned tabs are supported, and get pinned (or unpinned) by moving them into (or out of) a special branch called "Pinned" at the top of a window.

To pin or unpin a tab:

  • Use the browser's native functions: Right click a tab in the browser's tab bar. In the pop-up menu, click the "Pin" or "Unpin" option. The tab should become pinned (or unpinned), along with all its child tabs. The branch should move into (or out of) the special "Pinned" branch in TKTSTO. If you have no "Pinned" branch, it should create one automatically.

  • Move nodes in the Tree View: Use TKTSTO's sidepanel or other Tree View to move nodes or branches into or out of the Pinned branch. The browser's internal "pinned" state and tab bar should update accordingly.

The TKTSTO Tree View will generally be more reliable than the browser's native functions, so I recommend doing it that way in most cases.

Browser's native Pin/Unpin functions

Note how a new node was created, called Pinned. This node is special. It cannot be moved while it has loaded tabs, so it has an " anchor" icon next to it. It is locked in place at the top of the window... because that is what it means to be pinned.

All the children of "Pin Me!" got pinned too. The nested branch structure is preserved, so the branch and all its children get pinned or unpinned as a group.

But then you change your mind, and want to unpin it. Right click on the "Pin Me!" tab again in the browser's native tab bar. Then click "Unpin". This is what happens:

The entire branch gets unpinned. And since the "Pinned" branch no longer has any loaded tabs inside, it is no longer locked in place. It changes from an " anchor" to a " thumbtack" icon. In this state, it can be moved, but it'll lose its magic (and its thumbtack icon). It is only special when it is the first node in a window.

Pin/Unpin using TKTSTO

If you have no "Pinned" branch yet, make one. Put the cursor on the window node, expand it, then press o (addNodeAsNextVisibleRow) to add a new node. Set the label to "Pinned".

Then use whatever method you want, to move nodes or branches into or out of the Pinned branch. The browser's internal "pinned" state and tab bar should update accordingly.

If you want to unpin everything, simply delete the "Pinned" node while it is expanded. Or change its name, since "Pinned" is a magic word and changing the name removes the magic. Or you could move all its children somewhere else.

Don't delete it while it's collapsed though, since that will also delete everything inside it. (unless, of course, you want to delete the entire branch)

Caveats / Known Issues

  • Vivaldi is weird. If you close a window with pinned tabs in Vivaldi, and you use the browser's native functions to close the window (like clicking on the "X" in the upper right corner of a window), Vivaldi moves all the pinned tabs to a different window before closing it.

    I don't know why. No other browser seems to do this. It's weird.

    The problem is... it removes those tabs before TKTSTO can save the window. So the pinned tabs won't be in the saved window, and they won't be restored when you re-open the window again later.

    So you should probably use TKTSTO's Unload button to close the window instead. Then it will be saved correctly, and can be fully restored later without any missing tabs.

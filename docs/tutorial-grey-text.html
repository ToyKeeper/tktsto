Grey text is an unloaded tab.

But now that you've opened it, the text probably changed color and became bold, because it is open and "active". Open tabs are shown in a brighter color than saved tabs, and the browser's current tab is shown in bold.

And the sidepanel's cursor probably greyed out too, to show that the panel no longer has keyboard focus.

Try clicking between this page and the sidepanel a few times to see how the colors change as focus moves.

Then try unloading this page. There are a few ways to do this:

  • Press Alt+U to unload the current page.
  • Hover the mouse over a node in the side panel and click the "U" button in the "hover menu".
  • Put the panel cursor on a node and press the "U" key on the keyboard.
  • Or just close the page normally. It has a note attached, so it is "interesting" and will be saved automatically. Any node with a label, note, or checkbox is considered "interesting", and is kept in the tree when its browser tab is closed.

Any time you unload a tab, it will be kept in the tree session in the sidepanel. You can open it again later to continue where you left off.

For reference, when you close a tab, using regular browser actions like Ctrl+W or by clicking the tab's "X" button in the tab bar, the result depends on that tab's metadata in the tree session:

  • If the tab has any metadata attached, like a label or note or checkbox, it will be saved. That means the tab is "interesting", and won't be deleted when you close the tab.
  • If the tab has any interesting children, the tab will be saved. So if any child node has a label, note, or checkbox... the parent will be saved when closed. This applies to direct children only, not grandkids.
  • If the tab is "boring" and it has no "interesting" children, it will be deleted from the tree session when the tab is closed. And if it has any children, they will be promoted to the parent's position in the tree.

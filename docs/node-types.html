Node Types

Nodes come in several flavors:

Every node can have a label, note, checkbox, and children.

A branch is simply a node with children. It can be any node type.

A leaf is a node with no children.

Every branch can be expanded or collapsed, and every node can be marked and/or have the cursor on it.

A blank row is just a label with a Space inside. A divider is just a label with a - or = inside.

Some types may require additional explanation:

  • wasLoaded tabs are documented in more detail in the dedicated wasLoaded help page.
  • Discarded tabs are tabs that the browser has partially unloaded (suspended/hibernated). They still appear in the browser's tab bar. Focusing one reloads it.
  • Hidden tabs exist in Firefox-based browsers. They are not displayed in the browser's tab bar, but behave like regular tabs.
  • An empty node is a label node with no label text. It shows the node ID instead.

Organization

The session tree can mostly be organized however you want, but there are a few restrictions:

  • The root node cannot be moved or deleted.
  • Loaded tabs must be inside a window node.
  • Loaded tabs cannot be moved between a regular window and an incognito window.
  • A loaded window node cannot be converted into a non-window node unless it is nested inside another window node with the same incognito status.
  • The Pinned branch is special and cannot be moved while it contains any loaded tabs.
  • Native browser tab groups cannot contain other tab groups (nesting tab groups is not allowed by the browser).

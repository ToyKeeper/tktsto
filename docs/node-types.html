Node Types

Nodes come in several flavors:

Every node can have a label, note, checkbox, and children.

A branch is simply a node with children. It can be any node type.

A leaf is a node with no children.

Every branch can be expanded or collapsed, and every node can be marked or have the cursor on it.

A blank row is just a label with a Space inside.

Some types may require additional explanation:

  • wasLoaded tabs are documented in more detail here.
  • Discarded tabs are tabs that the browser has partially unloaded. They are sometimes called a "hibernated" tab or a "suspended" tab or, confusingly, some browsers or extensions call them "unloaded" tabs. But they are not fully unloaded. They still appear in the browser's tab bar, and the browser has simply paused them and remove some of their data from memory. Focusing one loads it back to the state it was in before, usually. A discarded tab will typically keep any unsubmitted form data intact.
  • Hidden tabs only exist in Firefox-based browsers. These are not displayed in the browser's tab bar, but they otherwise behave the same as other tabs. If you close a window while it has hidden tabs, then expand the branch while looking at the saved window node, it will likely contain tabs which are hidden, "wasLoaded", and possibly discarded.
  • An empty node is a label node with no label. It looks like "node 1kk4mnwnq--pc". If it has no text to use as its title, it shows the node ID instead.

Organization

The session tree can mostly be organized however you want, but there are a few restrictions:

  • The root node cannot be moved or deleted.
  • Loaded tabs must be inside a window node.
  • Loaded tabs cannot be moved between a regular window and an incognito window.
  • A loaded window node cannot be converted into a non-window node (like a label) unless it is nested inside of another window node with the same incognito status. Because loaded tabs must be in a window.
  • The " Pinned" tab is special and cannot be moved while it contains any loaded tabs. Also, it is only special when it is the first child of a window node. Otherwise, it's just a regular label.
  • Native browser tab groups cannot contain other tab groups. The browser does not allow them to be nested.
